LostVille: Find Hidden Objects

My Team Role

2D Game Artist & Asset Integrator

Duration

7 Months

Engine & Stack

Unity, Photoshop, Midjourney AI

Project Status

Commercially Released (Mobile)

Elevator Pitch

LostVille: Find Hidden Objects is a commercially released casual mobile game that seamlessly blends classic hidden-object mechanics with light city-building progression loops. Players explore rich, beautifully illustrated environments to find concealed items and earn in-game currency used to restore and upgrade their virtual town. As a 2D Artist on the project, my primary focus was delivering high-fidelity environmental art assets and interactive props, establishing a precise balance between strict visual aesthetics and immediate gameplay asset readability.

Core Art Production & AI Pipeline

In the mobile hidden-object genre, visual design is deeply tied to the core game design loops. To accelerate content production cycles while keeping art quality exceptionally high, I integrated generative AI-assisted workflows (Midjourney) into our daily design sprint pipeline. I utilized generative models during early pre-production for rapid asset ideation, testing compositional structures, and setting initial color palettes.

Once the core composition received a sign-off from our Lead Artist, I shifted to manual asset production using Photoshop. This included comprehensive asset clean-up, detailed manual digital painting, object isolation, and fine-tuning object rendering. Every single hidden asset had to organically blend into the rich environment while remaining sufficiently distinct and high-contrast to guarantee instant player readability on smaller mobile viewports.

Production Scene 01: Final render pass of an active in-game hidden-object level featuring complex environment layouts.

Unity Integration Pipeline: My production responsibilities extended far beyond asset exporting. I personally owned the asset integration pipeline within Unity. This involved building and maintaining scenes in the scene hierarchy, configuring core parameters in the Inspector, assembling UI components using strict anchor alignment logic, and executing resolution-scaling tests to ensure pixel-perfect canvas behavior across modern mobile screen dimensions.

Production Scene 02: Managing render layering, asset occlusion, and sprite depth ordering inside the engine environment.

UX/UI Design & Asset Optimization

A core challenge of the project was developing user interface elements that naturally complemented the vibrant, casual art style without cluttering the player's cognitive capacity. I designed and rendered a series of UI assets for various sub-menus, in-game storefronts, and town progression overlays.

Every asset underwent strict mobile platform optimization. Texture atlases were configured efficiently to keep runtime memory consumption low, and interactive button bounds were set up in accordance with mobile UX guidelines to prevent accidental touches during active gameplay sessions.

UI & Layout Showcase: Clean casual UI component design integrated directly into Unity production scenes.

Summary

The title was successfully shipped and released onto global mobile storefronts. Over my 7-month tenure as a 2D Game Artist, I helped establish a highly efficient content pipeline bridging traditional digital painting with modern generative toolsets. The production аassets I integrated inside Unity ensured excellent runtime performance and delivered a strong layer of visual polish tailored perfectly to the expectations of the casual mobile market.
