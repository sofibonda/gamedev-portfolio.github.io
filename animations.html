2D Bone-Based Character Animation

My Role

2D Artist & Animator

Project Type

Personal Study Project

Engine & Package

Unity (2D Animation Package, Sprite Skinning), Photoshop

Description

A small study project focused on creating 2D bone-based animations in Unity. The main goal was to establish a solid pipeline for character cutting, rigging, and setting up vertex weights to achieve smooth skeletal deformations. The final setup includes a fully functional animation controller covering basic movements and interactive animation states.

My Tasks

  • Character Art Cutting: Drew and split the original character concept into separate, optimized body parts in Photoshop, ensuring proper texture padding for joint rotations.
  • Rigging & Weighting: Imported character assets into Unity and created a fully operational skeletal bone hierarchy using the native 2D Animation Package.
  • Skin Weight Adjustments: Manually painted and adjusted sprite skin weights so the character's organic parts deform correctly without texture stretching or artifacting.
  • Animation Production: Authored several seamless 2D animations from scratch, including state loops for idle, walk, wave, fly, and land.
